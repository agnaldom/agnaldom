Postmortem: Resolving TCP 443 Handshake Stall in Kubernetes

MTTR: 45 min • Severity: Critical

Incident Symptom

Following a production microservice release, pods immediately fell into a CrashLoopBackOff restart cycle. The default team assumption was Redis failure, a shared critical dependency.

Isolation Method

Tested Redis independently: connection pool and latencies were completely green. Isolated outbound external dependencies: DNS resolved the authentication endpoint, but the TCP SYN on port 443 stalled with zero ACK response.

True Root Cause

Workload was scheduled onto a newly provisioned node pool and subnet where cloud security group egress rules had not yet been applied, silently blackholing outbound HTTPS traffic.

Resolution & Safeguards

Network rules were applied, recovering service in 45 minutes MTTR. Deployed immediate synthetic dependency monitoring, Pod NotReady alarms, and automated container restart rate tripwires.
